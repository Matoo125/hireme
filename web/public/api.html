hireme API

Read-only, public JSON over the same deduplicated job list as hireme.sk, refreshed daily.

No key needed. Any origin may call it (CORS). Limit: 60 requests per minute per IP. Responses carry an ETag; send it back as If-None-Match to get a 304 when nothing changed. The full contract is openapi.json; within v1, fields are only added.

Endpoints

EndpointReturns
GET /api/v1/jobsFiltered, sorted, paged jobs
GET /api/v1/jobs/{id}One job, with descriptions
GET /api/v1/facetsEach filterable field's values with job counts
GET /api/v1/metaLast scrape time, totals per board

Filtering /api/v1/jobs

ParameterMeaning
qText in the title, organization or description
sourceJob board
job_type, experience, education, location, cause_area, skillsTyped tags; see /api/v1/facets for values
organization, currency, periodExact organization name, salary currency, salary period
europeyes, no or unclear: whether someone living in Europe can take the job, read from the full posting
salary_minSalary (max, or min if no max) at least this; jobs without a parsed salary are left out
posted_since, closes_afterDates, YYYY-MM-DD; jobs without a close date pass closes_after
new_sinceJobs hireme first saw on or after this date (first_seen); pass the date of your last check to get only new jobs
sortnewest (default), oldest, closing, organization
fieldssummary (default) or full for descriptions
limit, offsetPaging; limit 1–200, default 50

Repeat a parameter to match any of its values; different parameters must all match. Unknown parameters are a 400, so a typo never silently returns everything.

curl 'https://hireme.sk/api/v1/jobs?location=Remote&cause_area=AI+safety+%26+policy&sort=closing&limit=20'
